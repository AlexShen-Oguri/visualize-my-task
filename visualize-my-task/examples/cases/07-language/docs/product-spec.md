# Harbor Notes product specification

## Goal

Help a person locate a saved note by title and inspect where the note came from. Note titles and source paths remain in the language used by their original documents.

## Requirements

- A title filter narrows the visible list without editing source documents.
- The note detail view displays the original source path.
- Keyboard focus remains visible when moving between the list and note detail.
- An empty result explains that no saved note matches the filter.

## Acceptance criteria

These are criteria to evaluate later, not a record of completed checks or human approval. The implementation plan records development, verification, human acceptance and delivery separately.

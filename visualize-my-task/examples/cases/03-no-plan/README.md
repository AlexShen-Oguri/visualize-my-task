# 案例 03：已有应用，但没有计划文件

合成应用「纸灯便签」已经做过两次修改。这个目录故意只有 README.md 与 CHANGELOG.md，没有 PLAN.md、plan.md 或 BOARD.md。

这里的产品介绍与“也许以后做同步”的想法均不是已批准的任务。打开看板应显示 history-only、两条历史记录、零个任务；当前与下一步为空。看板不应自动创建计划，也不应把旧修改转成待办或验收结果。

## 产品介绍

纸灯便签保存临时想法。未来也许加入同步，但尚未定义范围或批准开发步骤。


无历史的对照位于no-records/：它同样模拟已有项目，但没有保存计划或changelog。打开该子目录将显示no-plan空态，不会自动生成任务。

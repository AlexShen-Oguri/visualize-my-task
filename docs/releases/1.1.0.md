# Visualize My Task 1.1.0

本版重做了看板界面，并补上了键盘、触屏和地址栏方面的操作。计划文档、来源规则、命令行参数和 `/api/plan` 的数据结构都没有变化，已有项目不需要修改任何记录。运行要求仍是 Node.js 20+ 和本机浏览器，零第三方运行依赖。

## 界面

- 任务牌改为深色地形图上的不透明白牌，编号用黑色窄体字；锁定和记录不足的任务使用深色牌。
- 每块任务牌右上角有四个标记，依次对应开发、验证、验收、交付，不打开详情也能看出任务停在哪一步。牌左侧的六边形徽记表示任务在路线上的状态，例如开发完成、当前执行、下一任务、可开始、待解锁。
- 路线改为 45° 折线，会绕开任务牌和名称行。前置任务已完成的路线会点亮；挂接位置用虚线表示，不再和阻塞依赖混在一起。
- 任务详情面板改为不透明，按四态记录、说明、前置任务、后续任务、挂接位置、依据、任务属性排列。
- 底部信息条显示完成数量、四项状态各自的进度，以及当前任务和下一步的快捷入口。
- 手机上顶栏分为两行，任务详情改为底部抽屉。

## 操作

- 方向键按地图上的位置在任务牌之间移动，回车打开详情，Esc 关闭。
- 触屏支持双指缩放；鼠标滚轮缩放，触控板双指滑动平移、捏合缩放。
- 窗口尺寸变化时地图会自动重新取景，直到你手动移动地图为止。
- 地址栏会记录当前任务、所在地图和打开的面板，例如 `#task=P-01`、`#view=release&task=REL-01`、`#panel=sources`。刷新后保留，也可以存成书签。
- 所选文档保存后，状态有变化的任务牌会闪一下，并向读屏软件播报。

## 修复

- 聚焦或点击任务牌时，浏览器可能滚动地图容器，使画面与缩放、定位错开。
- 只有规范、没有任务记录的项目里，地址栏指定的面板不会打开。

## 安装与升级

在 [v1.1.0 Release](https://github.com/AlexShen-Oguri/visualize-my-task/releases/tag/v1.1.0) 下载 `visualize-my-task-1.1.0.zip` 和对应 `.sha256` 文件。安装包约 369 KB，上一版约 2.4 MB，差别主要来自地形底图由 PNG 换成了调色后的 JPEG。

从 1.0.0 升级时，请先删除或移走 `~/.codex/skills/` 中原有的 `visualize-my-task/`，再解压新的完整目录，不要直接覆盖：旧版的 `assets/terrain.png` 已不再使用，覆盖安装会把它留在原处。正在运行的看板需要重新启动，然后刷新浏览器。

用法与上一版相同，见 [仓库 README](../../README.zh-CN.md)。

## 包含与边界

安装包的构成和上一版一致：运行脚本、界面资源、测试、工作流参考和合成案例，共 49 个文件。字体许可保留在 [SIL Open Font License 通知](../../visualize-my-task/assets/OFL-BarlowCondensed.txt)。

服务仍然每两秒只读同步所选来源，绑定本机 `127.0.0.1`，不写入源文档、不监听对话、不调用模型。页面的内容安全策略没有放宽，字体内嵌在页面里，不发出任何外部请求。本版新增一处浏览器本地存储，只用来记住图例是展开还是收起。界面目前只有深色主题。

# Visualize My Task 1.2.0

本版补齐 Codex、Claude Code 和 Cursor 的安装与发布流程。三种工具使用同一份完整 skill 目录，看板运行需要 Node.js 20+ 与本机浏览器。

## 安装与调用

使用 Skills CLI 可同时安装到三个工具。当前安装器需要 Node.js 22.20+，也可以下载 ZIP，把完整目录放到对应工具的技能目录中。具体命令和目录见 [安装说明](../../README.md#安装)。

Codex 使用 `$visualize-my-task`，Claude Code 使用 `/visualize-my-task`，Cursor 在 Agent 聊天中通过 `/` 选择技能。技能从自身位置解析脚本和资源，按宿主能力打开浏览器或返回本机 URL，并通过宿主的长驻进程功能保留看板服务。

修复 Windows 临时目录使用短路径别名时，安装包中的看板和计划初始化脚本启动后直接退出的问题。

## 验证与发布

`npm test` 在技能目录调用 Node 的测试发现机制，可用于不同系统的默认 Shell。打包脚本明确使用 UTF-8 读取资料并解析子进程输出，支持包含中文和空格的独立安装路径。

GitHub Actions 为推送与 PR 配置 Linux、Windows 的 Node.js 20 测试，并在 Node.js 24 上用 Skills CLI 1.9.0 验证三个宿主的安装入口。发布工作流核对 Git 标签、`package.json` 和技能元数据的版本，运行测试，独立解压验证安装包，然后上传 ZIP 和 SHA256 校验文件。

本机验证覆盖源码测试、独立解压后的测试与 CLI 案例，以及三个宿主目录的真实安装和脚本启动。Linux 和 Windows 的托管运行结果见 [GitHub Actions](https://github.com/AlexShen-Oguri/visualize-my-task/actions)。Claude Code 与 Cursor 的 AI 交互会话仍需验证。

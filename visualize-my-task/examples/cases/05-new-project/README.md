# 案例 05：新项目从第一天使用 skill

合成项目「萤点计时器」从 2026-10-14 启动就使用 lowercase plan.md。initial 与 updated 是同一个项目在两个时间点的快照，不是要一起读取的两份计划。

| 快照 | 内容 | 应看到 |
| --- | --- | --- |
| initial/plan.md | 原批准的三个任务与初始变更记录 | P-01 当前，P-02 下一步，3 个任务 |
| updated/plan.md | 第一项完成、第二项进行中，追加暂停恢复修复与日期记录 | P-02 当前，ADD-01 下一步，4 个任务 |

P-01、P-02、P-03 的编号和任务身份保持不变。ADD-01 从 P-02 分出，在 P-03 前汇合；P-03 的前置条件保留 P-02 并追加 ADD-01。变更记录只解释何时、为何修改计划，不再复制一遍任务列表，不构成第四/第五个任务。

打开 updated 默认演示后续改动；打开 initial 可查看起点。两份计划都保留四个状态维度，未知信息明确写为“未记录”，不会把自动测试通过写成人工验收通过。

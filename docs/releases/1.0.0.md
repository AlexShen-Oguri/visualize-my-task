# Visualize My Task 1.0.0

首个版本提供从 Markdown 项目记录到本地开发行动图的完整工作流。需要 Node.js 20+ 和本机浏览器，运行时零第三方依赖，无需安装依赖或构建。

## 本版能力

- 展示项目实际使用的计划、规范、历史和可选关系文档；开发、自动验证、用户验收、交付四种状态独立保留。
- 支持主线、追加支线、跨工作类型依赖，以及无计划、仅历史和仅规范的项目。
- 中文／英文界面可跟随项目语言声明，或用 `--lang en` / `--lang zh` 手动选择；来源内容保留原文。
- 新项目可从第一天维护 `plan.md`；已有项目沿用自己的权威计划和文档位置。
- 提供完整合成案例和自动回归测试，供预览与独立验证。

## 安装与使用

在 [v1.0.0 Release](https://github.com/AlexShen-Oguri/visualize-my-task/releases/tag/v1.0.0) 下载 `visualize-my-task-1.0.0.zip` 和对应 `.sha256` 文件。将完整的 `visualize-my-task/` 解压到 `~/.codex/skills/`，在目标项目调用：

```text
$visualize-my-task 打开这个项目的开发看板
```

也可直接运行安装目录中的 `scripts/board.mjs`，用 `--root` 选择项目，用 `--plan`、`--spec`、`--changelog`、`--relations` 指定实际来源。先用 `--check` 核对，再用 `--port 0` 启动。详见 [仓库 README](../../README.md)。

## 包含与边界

安装包包含运行脚本、界面资源、测试、工作流参考和合成案例，排除私人记录、旧 UI 设计、开发归档及验证快照。字体许可保留在 [SIL Open Font License 通知](../../visualize-my-task/assets/OFL-BarlowCondensed.txt)。

服务每两秒只读同步所选来源，绑定本机 `127.0.0.1`，不写入源文档、不监听对话、不调用模型。初始化和计划维护由代理或单独的辅助脚本在授权范围内执行。此服务用于本机查看，不能通过代理或隧道开放到公网。缺少记录的状态保持未记录，自动检查结果不能替代用户验收。
